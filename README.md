## Backend Architecture

I enjoy designing backend systems where business logic, background processing, caching and real-time communication work independently.

```mermaid
flowchart TD
    A[React / Next.js Client] --> B[Express API Gateway]
    B --> C[JWT Authentication]
    B --> D[Business Logic Layer]
    B --> E[Socket.IO]

    D --> F[(MongoDB / PostgreSQL)]
    D --> G[(Redis Cache)]

    E --> G
    D --> H[BullMQ]
    H --> I[Background Workers]
    I --> J[External Services / Notifications]
```

**Architecture interests:**
- Modular backend architecture
- REST API design and authentication
- Redis caching and pub/sub
- Asynchronous processing with BullMQ
- Database optimization
- Distributed systems and scalability
